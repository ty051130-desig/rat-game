# Rat Escape Prototype v6

## 追加内容
- スマホ用仮想スティック
- スマホ用リスタートボタン
- タッチ操作向けUI調整
- 横画面推奨表示
- PCのWASD/矢印操作は従来通り
- 主人公モデルは `assets/models/main_character.glb` に配置

## 起動
```bash
bash basement_escape_prototype_v6/start_server.sh
```

PC: `http://localhost:8000/`

スマホ: 同じWi-Fiに接続し、PCのLAN IPを使って `http://PCのIP:8000/` を開きます。
WSL2のネットワーク設定やWindows Firewallによっては追加設定が必要な場合があります。
